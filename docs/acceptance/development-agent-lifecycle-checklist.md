# 开发agent生命周期与资源回收验收清单

任务：DEV-LIFECYCLE。状态：保留批准的验收设计，末节记录本分支的自测与实际验证边界；独立审核、真实合并和真实回收另行核验。

对应[开发规格](../design/development-agent-lifecycle-spec.md)。原共用清单T14—T17、T20在本任务覆盖；B系列编号是本任务验收范围。

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| B01 | 明确开发任务实际派发 | 唯一绑定spec、任务、实际agent、工作树和一个PR，不虚填未取得身份 |
| B02 | 查询、解释、资料查阅或只读分析 | 主会话处理，不创建开发agent；集成审核不另设长期审阅agent |
| B03 | 未完成需求因原目标缺陷返工 | 原agent、工作树和PR继续，不提前回收上下文 |
| B04 | 独立新需求需要开发，旧agent空闲或熟悉同模块 | 新需求独立派工或排队，不借用旧需求执行者 |
| B05 | 仅模型完成、测试通过、验收通过或PR创建 | 未结束，不据此回收开发agent或工作树 |
| B06 | 已测提交合入目标main并核对交付 | 记完成，立即保全并触发回收，不等待部署 |
| B07 | 用户明确取消未完成需求 | 先保全、关闭PR再清理，记取消，不伪造完成/合并 |
| B08 | 取消时没有PR，或其它任务确有依赖 | 不造PR；集成核实具体影响，不连带取消其它需求 |
| B09 | 回收请求含主/集成agent、共享资源、他人工作树或在用对象 | 越界项不执行，受保护与实际依赖对象不变 |
| B10 | 关闭或清理失败、超时、结果未知 | 保留待回收和责任者，成功步骤不重复，未知不盲重发 |
| B11 | 重复回收、旧授权，或PID/agent身份变化 | 不误清新对象、不重复释放，不用过期证据放行 |
| B12 | 交付回收后提出新修改 | 新建需求关联旧记录，不复用不存在的旧agent或保留长期模块岗位 |

## 实际项目验证

1. 本需求按一个spec、工作树、开发agent及PR实施，真实身份和授权如实记录。
2. 合并前原作者、上下文及必要验收环境可用，集成缺陷由原作者修复。
3. 集成核对合并后保全并回收本需求真实开发agent及专属资源，记录正式工具结果和实际资源状态。
4. 主会话、长期集成者、其它需求和数据不受影响。未能核实关闭时保留待回收，不把夹具当真实释放证明。

取消、未知结果等失败边界用明确测试数据验证，不为演示取消真实需求，不创建无开发目标的只读actor。

## 交付判定

- [ ] B01—B12有绑定当前源码的执行结果，保留失败/修复/复跑和未执行说明。
- [ ] 合并与回收分别有证据，实际合并后再核验真实回收。
- [ ] 主/集成角色、共享对象及其它任务资源不变。
- [ ] 取消不绕过原正常完成门槛，不冒充完成或发布。
- [ ] 正式宿主操作有当前授权；受限/未知有下一责任者，不虚报全平台可用名额。

开发前不得勾选；资料核对、自测、验收、非作者审核及真实资源核验分别说明证明范围。

| B11 | scope/generation/路由变化、路径换对象、重复操作拒绝误清；外部原件清理后仍可核保全，旧事实不冒充新身份 |
